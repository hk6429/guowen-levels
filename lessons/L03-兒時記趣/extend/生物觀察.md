# 生物觀察：癩蝦蟆真的會吃蟲嗎？

課文裡的癩蝦蟆「舌一吐而二蟲盡為所吞」，這不是沈復誇大。癩蝦蟆就是蟾蜍，牠的舌頭根部長在嘴巴前端，可以像彈簧一樣瞬間往前甩出去，表面還有黏液，蟲子一碰到就黏住，整個過程不到零點一秒，難怪小沈復只來得及「呀」一聲。

蟾蜍主要吃螞蟻、蚊子、蒼蠅、蛞蝓這些小東西，一個晚上可以吃掉上百隻，是花園裡的天然除蟲隊。牠皮膚上一顆顆的疙瘩會分泌毒液，所以貓狗咬到會流口水、嘔吐。小沈復「捉蝦蟆，鞭數十」其實有點危險，摸過之後一定要洗手。

台灣常見的是黑眶蟾蜍和盤古蟾蜍，校園的水溝邊、花臺下常常找得到。下次下雨後，蹲下來「使與臺齊」看看：你能在你家附近找到哪一種蟾蜍，牠正在吃什麼？
